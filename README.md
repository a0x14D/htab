## Why This Exists

**Everyone's vibecoding their dream setup these days. So why not vibe‑code your new tab too?**

Most new tab pages are ad platforms in disguise. This one respects your time, your privacy, and your muscle memory. **Four different lives. One terminal.**

<div align="center">

| 😴 **Personal** | 🔍 **Research** | 💻 **Dev** | 🚩 **CTF** |
|:---:|:---:|:---:|:---:|
| 🟢 green | 🟡 amber | 🔵 blue | 🔴 red |
| mail, maps, chat | Shodan, VT, crt.sh | GitHub, MDN | HTB, CTFtime |

## Quick Start

### Static (fastest)
```bash
git clone https://github.com/a0x14d/htab.git
cd htab
# Open index.html directly or serve locally
python3 -m http.server 8000
```

### With Vite (dev)
```bash
git clone https://github.com/a0x14d/htab.git
cd htab
npm install
npm run dev
```

See **[Development](docs/DEVELOPMENT.md)** for full setup and **[Deployment](docs/DEPLOYMENT.md)** for making it your new tab.

## Highlights
- **Keyboard-first** — ` / `, `n`, `q`, `1-4`, `:` commands
- **Per-mode everything** — links, notes, todos, accents
- **IOC pivots & decoders** — paste and go
- **Backup/restore** — `:export` / `:import`
- **Privacy-first** — no backend, no telemetry, localStorage only
